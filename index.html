            ✍️ The 3 Ways to Draft Variables in Any Prompt
          


          

            
            

              

                1. Double Braces (Native Standard)
                Recommended
              

              

                Standard syntax for text inputs and dropdown pills:
              

              {{topic}}
              {{tone: Professional | Direct | Casual}}
            


            
            

              

                2. Square Brackets (Natural Writing)
                Fast & Easy

              [Company Name]
              [Investor's Name or Investor Type]
            


            
            

              

                3. Single Braces
                Auto-Detected

              {specific industry or market}

1. The 5-Section Modular Blueprint Anatomy

              

                Traditional prompting relies on fragile, one-line requests that produce erratic, generic outputs. PromptVault Pro employs an enterprise 5-part architecture that anchors large language models (LLMs) to rigorous, deterministic performance.
              


              

                "Every great prompt shares common structural elements. Understanding these components allows you to construct prompts systematically rather than through trial and error. Think of these components like LEGO bricks."
                — Fatih Kadir Akın, The Prompting Book (Foundations: Anatomy of an Effective Prompt)
              


              

                
                  

                    Section
                    What It Represents
                    How the AI Agent Interprets It
                    If Omitted vs. Provided
                  

                
                
                  

                    1. Role / Persona
                    Domain identity, cognitive framework, voice, and level of seniority.
                    Activates high-depth domain weights and specialized technical vocabulary.
                    Omitted: AI defaults to a generic polite assistant.
Provided: Speaks with senior authority.		
                  

                  

                    2. Primary Objective
                    Unambiguous deliverable statement and mission scope.
                    Focuses attention mechanisms on the primary goal, preventing conversational drift.
                    Omitted: Wanders off-topic into surface summaries.
Provided: Direct, laser-focused execution.		
                  

                  

                    3. Dynamic Context & Inputs
                    Strict parameter slots with {{variables}}.
                    Treats inputs as isolated operational data payloads distinct from instructions.
                    Omitted: Prompt is hard-coded for 1 scenario.
Provided: Reusable across infinite projects.		
                  

                  

                    4. Negative Guardrails
                    Anti-patterns, prohibited assumptions, hallucination limits.
                    Sets boundary filters that prune inappropriate response branches before token generation.
                    Omitted: Models guess and fabricate data.
Provided: Zero fluff, strict adherence.		
                  

                  

                    5. Output Rubric & Schema
                    Structural format (tables, JSON) and quality evaluation criteria.
                    Provides self-evaluation checklist so the model audits its output before returning.
                    Omitted: Unstructured prose walls.
Provided: Production-ready, copy-pasteable data.		
                  

                
              

            


            
            

              
2. The Variable Multiplier: Why Dynamic Placeholders Matter

              

                The most important innovation in modern prompt systems is the Separation of Instructions and Data. In static prompt engineering, you have to rewrite the prompt every time a client or topic changes. With PromptVault variables, the prompt becomes a software template.
              


              

                "One of the most important habits in prompt engineering is clearly separating your instructions from your context... Mixing them together confuses the model about what to do versus what to use."
                — Fatih Kadir Akın, The Prompting Book (Core Prompting Principles)
              


              

                

                  
1. Free-Text Variables: {{variable_name}}

                  
Allows users to insert bespoke topics, URLs, customer names, or code snippets without editing the blueprint logic.

                


                

                  
2. Multiple-Choice Pills: {{tone: Professional | Technical | Conversational}}

                  
Restricts variables to high-impact proven values. Clicking pills in the runner replaces typing with 1-click execution.

                


                

                  
3. Why This Makes Prompts More Suitable & Flexible

                  
A single blueprint for "Executive Decision Memo" can serve 500 different business proposals simply by swapping {{initiative}}, {{budget}}, and {{risk_level}}. You curate once, and use forever.

                

              

            


            
            

              
3. Core Prompting Principles from Fatih Kadir Akın

              

                Key foundational concepts extracted directly from The Prompting Book to elevate everyday prompting into mastery:
              


              

                

                  
• Principle 1: Clarity Trumps Brevity

                  
Don't worry about making prompts as short as possible. Specificity and explicit constraints produce exponentially higher quality outputs than terse queries.

                


                

                  
• Principle 2: Role-Based Priming (The Persona Effect)

                  
Telling an AI "Act as a Senior Database Administrator" primes it to evaluate indexing, query plans, and concurrency rather than giving beginner textbook definitions.

                


                

                  
• Principle 3: From Prose to Data (Structured Output)

                  
Never ask for "some suggestions." Ask for a Markdown table with columns: Option | Pros | Cons | Estimated Effort (1-5). Structured formats force the AI to reason concretely.

                


                

                  
• Principle 4: Chain of Thought (Show Your Work)

                  
Ask the model: "First, analyze the underlying constraints step-by-step. Only then output the final recommendation." When models reason before answering, error rates drop dramatically.

                


                

                  
• Principle 5: Negative Constraints (The Guardrail Method)

                  
Telling the AI what NOT to do is as crucial as telling it what to do. Example: "Do NOT apologize, do NOT mention you are an AI, and do NOT use marketing buzzwords like 'game-changer' or 'revolutionize'."

6. AI Prompting Glossary & Technical Reference

              
              

                
                  

                    Term
                    Definition
                    Impact on Prompting
                  

                
                
                  

                    Token
                    The basic unit of text processed by LLMs (~4 characters or 0.75 words in English).
                    Both inputs and outputs consume context window tokens. PromptVault tracks tokens live.
                  

                  

                    Context Window
                    The total memory capacity an LLM can process in a single conversation.
                    Keep blueprints modular and focused so models don't suffer from attention degradation.
                  

                  

                    Temperature
                    A sampling parameter controlling randomness (0.0 = deterministic, 1.0 = creative).
                    Use 0.0–0.2 for Excel/Code/Memos; use 0.7–0.9 for creative ideation and storytelling.
                  

                  

                    Hallucination
                    When an AI confidently invents false facts, citations, or code APIs.
                    Prevented through Negative Guardrails and forcing the AI to admit unknowns.
                  

                  

                    Grounding
                    Anchoring the AI's response in explicit source text or supplied data inputs.
                    Using {{variables}} grounds the LLM strictly in your data.
                  

                  

                    Few-Shot Prompting
                    Supplying 1 to 3 concrete input/output examples inside the prompt.
                    Guarantees exact formatting and tone match better than paragraphs of description.

🔌 Setting Up the DeepWiki Remote MCP Server

              

                Cognition provides a public Model Context Protocol (MCP) server at https://mcp.deepwiki.com/mcp over Server-Sent Events (SSE). Adding this MCP server empowers your AI coding assistant to query DeepWiki documentation on demand for any public repository.
              


              

                
                

                  

                    Option A: Google Antigravity IDE
                    ~/.gemini/config/mcp_config.json
                  

                  
{

    }
  }
}

{

    }
